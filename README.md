# 🛍️ Online Shopping Purchase Prediction

### Predicting Customer Purchase Intention Using Machine Learning

---

## 📌 About The Project

Online Shopping Purchase Prediction is a Machine Learning classification project focused on understanding customer browsing behaviour and predicting purchase intention.

The project uses historical customer session data to identify patterns in online shopping activities and predict whether a website visitor is likely to complete a purchase or leave without purchasing.

The main focus is to understand customer behaviour and build a predictive model that can support data-driven business decisions.

## 🎯 Project Objectives

- Analyze online shopping customer behaviour.
- Identify important factors influencing purchase decisions.
- Understand purchasing patterns through Exploratory Data Analysis.
- Build Machine Learning classification models.
- Predict purchase and non-purchase outcomes for visitor sessions.

## 📊 Dataset Description

**Dataset:** Online Shoppers Purchasing Intention Dataset

The dataset contains information about website visitors, their browsing activities, session duration, visitor type, traffic source and purchase outcomes.

**Target Variable – Revenue**

| Value | Meaning |
|---|---|
| 1 | Purchase |
| 0 | No Purchase |

## 🔍 Exploratory Data Analysis

The following analyses were performed:

- Purchase vs Non-Purchase Distribution
- Monthly Website Visit Analysis
- Visitor Type Analysis
- Weekend vs Weekday Behaviour
- Product Page Visit Analysis
- Bounce Rate and Exit Rate Distribution
- Correlation Analysis
- Purchase Behaviour by Visitor Type
- Product Page Activity vs Purchase Behaviour

## ⚙️ Data Preprocessing

- Checked missing values and duplicate records.
- Removed duplicate records.
- Analyzed numerical and categorical features.
- Converted the target variable into numerical format.
- Applied One-Hot Encoding to categorical features.
- Separated independent and dependent variables.
- Split the dataset into training and testing sets.

## 🤖 Machine Learning Models

The following classification algorithms were implemented:

**1. Logistic Regression**

Used as a classification model to learn relationships between customer browsing features and purchase outcomes.

**2. Random Forest Classifier**

Used as an ensemble learning algorithm that combines multiple decision trees to predict customer purchase intention.

**Final Model:** Random Forest Classifier

## 📈 Model Evaluation

Model performance was evaluated using:

- Accuracy Score
- Precision
- Recall
- F1-Score
- Classification Report
